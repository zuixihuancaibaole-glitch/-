# 第二、三章补充资料

查阅日期：2026-11-06。以下是佐治亚理工数学学院官网的开放教材 *Interactive Linear Algebra*，作者 Dan Margalit、Joseph Rabinoff。已阅读对应正文，用于核对概念解释；本笔记中的航线计算、奇异矩阵反例、分块大小检查等是自行演算的例子。

教材按“方程组 → 几何 → 矩阵变换”组织，与本课程“行列式 → 矩阵 → 初等变换”顺序不同。阅读时按知识点对应，不要求照它的章号重学一遍。

| [§2.3 Matrix Equations](https://textbooks.math.gatech.edu/ila/matrix-equations.html) | $Ax$ 的列组合解释；哪些右端项可以有解 | [[2.1 矩阵相关概念]]、[[2.2 矩阵的运算]]、[[3.3 线性方程组的解]] |

先按 [[第二、三章学习导航]] 复习已有笔记，遇到“公式会用，但不知道为什么”时，再读表中对应章节。网页中的交互图可辅助观察，符号计算仍应回到具体矩阵与方程验证。

“列空间、零空间、维数、仿射子空间”用于连接已有计算与几何理解；基础解系与向量空间理论会在后续章节进一步展开。第二章给出的 $AP=P\Lambda$ 例题只要求使用已知条件，不表示每个矩阵都可对角化。
