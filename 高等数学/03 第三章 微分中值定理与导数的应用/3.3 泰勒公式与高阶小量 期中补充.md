# 3.3 泰勒公式与高阶小量 期中补充

本篇是期中补充，放在高阶导数、洛必达之后学习，用于连接高阶小量条件和抽象函数补点题。

## 一、有限阶展开的含义

若函数在零点附近具有所需的阶数的导数，麦克劳林展开为

$$f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(0)}{k!}x^k+o(x^n),\qquad x\to0.$$

**核心概念：$o(x^n)$ 表示它除以 $x^n$ 后趋于零，并不表示它等于零。**展开到分母要求的阶数；抵消越多，所需精度越高。常用二阶式为 $e^x=1+x+x^2/2+o(x^2)$、$\ln(1+x)=x-x^2/2+o(x^2)$。
